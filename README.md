# 2ndHeart — Configurator

Interaktiver 3D-Konfigurator für individuelle Gehäuse und Schnittmuster basierend auf Three.js.

## 🚀 Live Demo
Die Web-App kann direkt über GitHub Pages aufgerufen werden:
👉 **[https://tobiasjschreiber.github.io/2ndHeart/](https://tobiasjschreiber.github.io/2ndHeart/)**

## ✨ Features
- Interaktiver 3D-View mit Faltungsanimation (Flat to Case)
- Mainboard- und Bauteil-Konfiguration
- Export als `.svg`-Schnittmuster
- Responsive Oberfläche mit Clean Minimal Design
- Komplett im Browser lauffähig (Three.js via ES Modules / CDN)

## 🛠️ Lokale Ausführung
Einfach einen statischen Webserver im Projektordner starten:

```bash
# z.B. mit Python
python3 -m http.server 8000
```
und im Browser `http://localhost:8000` aufrufen.
